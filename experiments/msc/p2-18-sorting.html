📊 8085 — Ascending & Descending Order

🏠 Lab

Bubble sort: compare each number with the next one and swap them if they are in the wrong order. After every pass the biggest (or smallest) number has “bubbled” to the end. A flag in the D register remembers whether any swap happened.
