🧮 8085 — Sum of a Set of n Data (8-bit)

🏠 Lab

ADD M adds the byte in memory (address in HL) to the accumulator. If the answer is bigger than FFH it needs a ninth bit: that bit goes into the carry flag CY, and the program counts it in the C register so no part of the sum is lost.
